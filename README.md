# ajabwen

## متصفّح قواعد بيانات SQLite — ملف PHP واحد، للقراءة فقط

`sqlite-browser.php` أداة مستقلة (ملف واحد، بدون أي مكتبات أو بناء) تبحث تلقائياً في
المجلد والمجلدات الفرعية عن قواعد بيانات SQLite، وتفتحها **للقراءة فقط** لتصفّح كل
الجداول والعروض والبيانات والمخطط (Schema).

---

### ✨ ما الذي تقدّمه الأداة

| الميزة | التفصيل |
|---|---|
| 🔍 اكتشاف تلقائي | تبحث في المجلدات الفرعية عن `*.db / *.sqlite / *.sqlite3 / *.db3 / *.s3db …`، وتفحص أيضاً الملفات ذات الامتداد الغامض (`.dat`، بلا امتداد…) عبر **ترويسة الملف** `SQLite format 3\0` — فلا تخطئ ملفاً ولا تفتح ملفاً مزيفاً. |
| 🔒 قراءة فقط | أربع طبقات حماية مستقلة (التفاصيل أدناه). لا يوجد في الكود أي أمر كتابة إطلاقاً. |
| 🗂 تصفّح كامل | الجداول، العروض (Views)، الفهارس، المشغّلات (Triggers)، الجداول الافتراضية (FTS5…)، وتعريفات `DDL` الكاملة من `sqlite_master`. |
| 📄 شبكة بيانات | ترقيم صفحات، ترتيب بالنقر على أي عمود، بحث `LIKE` داخل كل الأعمدة، حجم صفحة قابل للتغيير. |
| 🔎 تفاصيل الصف | عرض عمودي لصف واحد بكل قيمه الكاملة، مع تنقّل (السابق/التالي). |
| 🧬 قيم BLOB | كشف تلقائي للبيانات الثنائية مع معاينة Hex وحجمها، وزر تنزيل الملف الثنائي. |
| ⬇️ تصدير | `CSV` (مع BOM ليفتح بالعربية في Excel) و`JSON` — للبثّ صفّاً بصف دون استهلاك الذاكرة، ويحترم البحث والترتيب الحاليين. |
| 🧮 استعلام للقراءة | لوحة استعلامات تقبل `SELECT / WITH / EXPLAIN / PRAGMA` فقط، وترفض أي أمر كتابة. |
| 🩺 فحص السلامة | `integrity_check` و`quick_check` عند الطلب، مع كل إعدادات `PRAGMA` للقراءة. |
| ⌨️ سطر أوامر | `--list / --tables / --schema / --rows / --sql / --info / --count`. |
| 🌐 واجهة عربية RTL | داكنة، متجاوبة، بدون أي مورد خارجي (لا CDN ولا خطوط ولا JS خارجي) — تعمل على شبكة داخلية معزولة. |
| 🛡 ترويسات أمان | `CSP`، `X-Frame-Options: DENY`، `X-Robots-Tag: noindex`، `Referrer-Policy`. |

### 🚀 التثبيت والتشغيل

1. ارفع الملف `sqlite-browser.php` إلى مجلد على السيرفر (مثلاً بجانب مجلد `backend`).
2. افتحه من المتصفح: `https://example.com/sqlite-browser.php`
3. سيبحث تلقائياً في مجلده وكل المجلدات الفرعية ويعرض ما يجده.

> **مهم:** الأداة تقرأ فقط، لكنها تكشف بيانات حساسة. ضَعها في مسار غير معلَن،
> وفعّل كلمة المرور (انظر أدناه)، واحذفها من السيرفر بعد انتهاء الحاجة إليها.

**بدون خادم (PHP مدمج):**

```bash
php -S 0.0.0.0:8080 sqlite-browser.php
```

**من سطر الأوامر:**

```bash
php sqlite-browser.php --list
php sqlite-browser.php --tables  backend/data/main.db
php sqlite-browser.php --rows    backend/data/main.db users --limit=20 --search=مكة --order=age --desc
php sqlite-browser.php --schema  backend/data/main.db users
php sqlite-browser.php --count   backend/data/main.db users
php sqlite-browser.php --info    backend/data/main.db
php sqlite-browser.php --sql     backend/data/main.db "SELECT id,name FROM users LIMIT 5"
```

### ⚙️ الإعدادات (أعلى الملف)

كل الإعدادات ثوابت في قسم `1) الإعدادات`، وأشهرها:

| الثابت | الافتراضي | الوصف |
|---|---|---|
| `SB_SCAN_ROOTS` | `[__DIR__]` | المجلدات التي يُبحث فيها (يمكن وضع أكثر من مسار). |
| `SB_SCAN_MAX_DEPTH` | `8` | أقصى عمق للمجلدات الفرعية. |
| `SB_SKIP_DIRS` | `node_modules, .git, vendor…` | مجلدات يتم تجاهلها. |
| `SB_DB_EXTENSIONS` | `db, sqlite, sqlite3…` | الامتدادات المقبولة. |
| `SB_SCAN_BY_CONTENT` | `true` | فحص الملفات الغامضة عبر ترويسة الملف. |
| `SB_ACCESS_PASSWORD` | `''` (معطّلة) | كلمة مرور لفتح الأداة. **يُنصح بضبطها.** |
| `SB_HMAC_SALT` | قيمة جاهزة | ملح توقيع الروابط — **غيّره إلى قيمة عشوائية خاصة بك.** |
| `SB_PAGE_SIZE` / `SB_MAX_PAGE_SIZE` | `50` / `1000` | عدد الصفوف في الصفحة. |
| `SB_SHOW_ROW_COUNTS` | `true` | عرض عدد صفوف كل جدول (يمكن إخفاؤه من الواجهة). |
| `SB_COUNTS_TIME_BUDGET` | `4.0` | ميزانية زمنية لحساب الأعداد قبل التخطي. |
| `SB_ALLOW_SQL_CONSOLE` | `true` | تفعيل/تعطيل لوحة الاستعلام. |
| `SB_ALLOW_NONRO_FALLBACK` | `false` | **اتركها `false`** — تسمح بفتح غير صارم عند الفشل. |
| `SB_EXPORT_MAX_ROWS` | `200000` | أقصى عدد صفوف للتصدير. |
| `SB_BLOB_MAX_BYTES` | `32MB` | أقصى حجم لتنزيل قيمة ثنائية. |

يمكن تجاوز أي ثابت دون تعديل الملف بإنشاء ملف صغير يعرّف الثوابت ثم يستدعي الأداة:

```php
<?php // config.php
define('SB_SCAN_ROOTS', ['/home/user/storeact/backend']);
define('SB_ACCESS_PASSWORD', 'كلمة-سر-قوية');
require __DIR__ . '/sqlite-browser.php';
```

### 🔒 ضمانات «القراءة فقط»

**أربع طبقات مستقلة — يكفي أي منها لمنع الكتابة:**

1. **على مستوى SQLite:** يُفتح الملف بالـ URI `file:…?mode=ro`.
2. **على مستوى PDO:** راية `PDO::SQLITE_OPEN_READONLY`.
   > الجمع بين الطبقتين 1 و2 مهم: بمفرده يسمح `mode=ro` بتنفيذ `ATTACH DATABASE`
   > الذي **يُنشئ ملف قاعدة بيانات جديداً** على القرص، بينما الراية `SQLITE_OPEN_READONLY`
   > تمنع `ATTACH` تماماً. وقد تم التحقق من ذلك عملياً.
3. **على مستوى الاتصال:** `PRAGMA query_only = ON` بعد كل اتصال.
4. **على مستوى الكود:** لا يُنفَّذ أي أمر كتابة؛ وأسماء الجداول/الأعمدة تُقتبس بعد
   التحقق من وجودها في `sqlite_master`، وكل قيم البحث تُمرَّر كمعاملات مرتبطة (Prepared Statements).

**حماية لوحة الاستعلامات:** يجب أن تبدأ الجملة بـ `SELECT/WITH/EXPLAIN/PRAGMA`،
وتُرفض الجمل المتعددة، وتُرفض `ATTACH/DETACH` رفضاً قاطعاً (حتى داخل نص مقتبس)،
وتُرفض أي `PRAGMA` تحتوي `=` أو تكتب على القرص (`wal_checkpoint`, `incremental_vacuum`, …).
ويُستخدم `prepare()/execute()` وليس `exec()`، لأن `exec()` في `pdo_sqlite` يُنفّذ أكثر من جملة.

**حماية المسارات:** كل قاعدة لها معرّف موقّع بـ `HMAC-SHA256`؛ ولا يُقبل أي مسار إلا إذا
كان `realpath` داخل `SB_SCAN_ROOTS` وتحقّقت ترويسة SQLite فيه. لذلك لا يمكن تحويل الأداة
إلى قارئ ملفات عشوائي (LFI) ولا الوصول إلى `/etc/passwd` وأمثاله.

**حماية المخرجات:** كل قيمة تُعرض تمرّ عبر `htmlspecialchars(ENT_QUOTES|ENT_SUBSTITUTE)`،
ومسارات الروابط عبر `rawurlencode`.

#### ملاحظة شفافة عن قواعد WAL

ملف القاعدة (`.db`) وملف اليوميات (`-wal`) **لا يتغيّر فيهما أي بايت** عند القراءة
(تم التحقق بمقارنة بصمة SHA-256 قبل وبعد). الشيء الوحيد الذي قد يتحدّث هو **الطابع الزمني**
لملف الفهرس المؤقت `-shm` (وهو ملف ذاكرة مشترك متطاير يُعاد بناؤه تلقائياً ولا يحتوي بيانات).
هذا سلوك SQLite نفسه مع أي قارئ بما فيه أداة `sqlite3` الرسمية.

إذا تعذّر فتح قاعدة WAL للقراءة (مجلد غير قابل للكتابة ولا توجد ملفات `-wal/-shm`)،
تسقط الأداة إلى وضع **لقطة ثابتة** (`immutable=1`) مع شارة تنبيه واضحة في الواجهة،
ولا يُستخدم هذا الوضع إطلاقاً عند وجود ملف `-wal` لأنه سيتجاهل أحدث البيانات.

### 🖥 دليل الواجهة

- **القائمة الجانبية:** كل القواعد المكتشفة مع الحجم وعدد الكائنات وشارة `WAL` وحالة الفتح، مع حقل تصفية فوري وزر «إعادة البحث».
- **نظرة عامة:** إحصاءات القاعدة، حالة الاتصال، ووضع `query_only`.
- **الجداول:** كل الجداول والعروض مع عدد الأعمدة والصفوف، وشارة للجدول الداخلي (`sqlite_*`) والافتراضي وجداول الظلّ لـ FTS5.
- **البيانات:** الشبكة مع الترتيب والبحث والترقيم والتصدير، وبطاقة «بنية الأعمدة» (الأنواع، `NOT NULL`، `PK`، الافتراضي، الفهارس، المفاتيح الأجنبية) وبطاقة `DDL`.
- **تفاصيل الصف:** كل عمود بقيمته الكاملة مع زر نسخ أو تنزيل للقيم الثنائية.
- **البنية (Schema):** كل كائنات `sqlite_master` مع تعريفها، داخل عناصر قابلة للطيّ.
- **معلومات القاعدة:** كل أوامر `PRAGMA` للقراءة + فحص السلامة + خيارات ترجمة SQLite.
- **استعلام للقراءة:** مع أمثلة جاهزة وتصدير النتيجة.

### ✅ الاختبارات

تم اختبار الأداة على PHP 8.3 مع SQLite 3.51 عبر **349 assertion** في أربع مجموعات،
وشملت حالات حدودية حقيقية:

- مسارات بأسماء عربية ومسافات ورموز `?` و`#`، وقواعد متداخلة بعمق، وملفات مزيفة بامتداد `.db`، وقاعدة تالفة (truncated)، ومجلدات `node_modules` التي يجب تجاهلها.
- جداول `WITHOUT ROWID`، وجداول FTS5 الافتراضية وجداول ظلّها، وجداول بأسماء فيها مسافات، وجداول فارغة، وقيم `NULL` و`BLOB` ونصوص طويلة.
- منع `INSERT/UPDATE/DELETE/DROP/CREATE/ALTER/REPLACE/VACUUM/ATTACH` وتغيير `PRAGMA journal_mode` — مع التحقق من أن **بصمة الملفات لم تتغير** وأنه **لم يُنشأ أي ملف جديد**.
- محاولات حقن SQL عبر معامل البحث ومعامل الترتيب ومعامل اسم الجدول، ومحاولات XSS، ومعرّفات موقّعة مزيفة، ومسارات خارج الجذر.
- صحة الترقيم (٥ صفحات × ٥٠ صفاً = ٢٥٠ بلا تكرار أو نقص) وصحة الفرز التصاعدي/التنازلي على أعمدة `INTEGER` و`REAL`.
- الحماية بكلمة المرور (دخول صحيح/خاطئ، كوكي مزوّر، حماية التصدير)، ووضع «اللقطة الثابتة» على مجلد غير قابل للكتابة.
- التصدير: عدد الأسطر وسلامة العربية في `CSV`/`JSON`، واحترام البحث الجاري، وتنزيل `BLOB`.

### 📋 المتطلبات

- PHP **7.4** أو أحدث (يُفضَّل 8.0+).
- امتداد **`pdo_sqlite`** (في cPanel: *Select PHP Version → Extensions → pdo_sqlite*).
- `mbstring` اختياري لكنه موصى به لاقتطاع النصوص العربية بشكل سليم.
- لا يحتاج أي مكتبة خارجية، ولا قاعدة بيانات، ولا كتابة على القرص (عدا تخزين مؤقت اختياري لنتيجة البحث في مجلد temp).
